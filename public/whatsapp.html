Der Bot nutzt die WhatsApp-Nummer, die du hier einmal verbindest. Die Verbindung bleibt gespeichert – auch nach Neustarts.

Möglichkeit 1: QR-Code scannen

  1. WhatsApp auf dem Bot-Handy öffnen
  2. Einstellungen → Verknüpfte Geräte → Gerät hinzufügen
  3. Diesen Code scannen:

QR-Code wird geladen…

Der Code erneuert sich automatisch.

Möglichkeit 2: Mit Telefonnummer

Praktisch, wenn du den QR-Code nicht scannen kannst (z. B. Dashboard auf demselben Handy).

  1. WhatsApp auf dem Bot-Handy: Einstellungen → Verknüpfte Geräte → Gerät hinzufügen
  2. Unten auf „Stattdessen mit Telefonnummer verknüpfen“ tippen
  3. Diesen Code eingeben (gilt ca. 2 Minuten)

Probleme?

„Neu verbinden“ hilft, wenn die Verbindung hängt. „Abmelden“ trennt das aktuelle Handy – danach musst du neu scannen.
